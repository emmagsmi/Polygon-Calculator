# Polygon-Calculator

# Program:
This program calculates the area and perimeter of 9 different shapes while dynamically storing them in a vector.
# Process:
The program outputs a menu with 12 different options: Add Triangle, Add Isosceles Triangle, Add Equilateral Triangle, Add Triangle, Add Rectangle, Add Square, Add Pentagon, Add Hexagon, Add Octagon, Display All Shapes, Display Statistics, and Exit. The program then prompts the user to input a number between 1 and 12, validates the input, and calls the appropriate function.
# Results: 
For menu options 1-9, the program prompts the user to input the length of the sides and the value of the angle (for quadrilaterals), calculates the perimeter and area, and displays a message stating that the polygon has been created. For menu option 10, the program displays the information of each shape stored in the vector. For menu option 11, the program displays statistics including the total number of shapes, the largest area, the average area, and the average perimeter. The program then redisplays the menu for user input. For menu option 12, the program exits the while loop and deletes all dynamically allocated memory.
